Pipeline walkthrough

Decision

Schedule the incremental load. Monitor watermark age and compare daily spend with the platform ledger after each refresh.
Assumptions and scope

One local HTTP source exposes an immutable snapshot per run. Pages contain up to 37 records. The extractor retries transient HTTP errors and commits the campaign-day upserts and watermark together. The fixture guarantees monotonic update times across snapshots. A live source with late or equal timestamps would need a lookback window or a stable change cursor.
